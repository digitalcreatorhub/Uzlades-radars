# Uzlādes Radars

Приложение для водителей электромобилей: куда ехать на зарядку в Риге, какие есть станции, какие разъёмы и мощность, сколько стоит. Установка на телефон как отдельного приложения (PWA). Не связано с «Degvielas Radars».

## Что умеет версия 1

- Карта станций Риги, цвет метки по классу мощности: AC (до 43 кВт), DC (50–149 кВт), 150+ кВт.
- Фильтры по разъёму (CCS, Type 2, CHAdeMO) и мощности.
- «Куда ехать»: лучшая станция по балансу расстояния, цены и скорости, с вариантами «дешевле» и «ближе». Маршрут в Google Maps или Waze.
- Список станций рядом, карточка станции, таблица цен по сетям.
- Русский и английский, тёмная и светлая тема, работа офлайн после первой загрузки.

## Чего пока нет

- **Статуса «свободно / занято».** В OpenStreetMap его нет. Он появится после подключения национальной точки доступа transportdata.gov.lv (нужен бесплатный API-ключ, и надо проверить, отдаёт ли она живой статус).
- Литвы и Эстонии. Сейчас только Рига.

## Откуда данные

- **Станции:** OpenStreetMap через Overpass API, запрос идёт из браузера пользователя, результат кэшируется на 12 часов. Данные © участники OpenStreetMap, лицензия ODbL. Ошибку в карточке станции можно исправить прямо на OpenStreetMap.
- **Цены:** диапазоны с сайтов операторов, сводка Cenotava.lv на 26.10.2026. Это ориентир, живые тарифы не подтягиваются. Правятся в `logic.js` (`PRICES`, `PRICES_DATE`).
- **Карта:** стандартные тайлы OpenStreetMap, © OpenStreetMap contributors. Для заметной нагрузки нужен свой поставщик тайлов (например, MapTiler с ключом).
